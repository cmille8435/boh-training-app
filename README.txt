BOH TRAINING APP — PROTOTYPE

Open index.html in a browser to preview.

Included:
- Welcome & Restaurant Tour
- Primary
- Secondary
- Machines
- Breading
- Fries
- Closing: Boards, Machines, Breading Table, Dishes
- Team-member progress checkboxes
- My Progress screen
- Trainer View

Important:
This prototype stores progress in the browser on one device (localStorage).
For multiple trainers/phones to share the same progress, the next version needs
a hosted database and user access/login.

The training wording is based on the checklist images supplied in the ChatGPT conversation.
